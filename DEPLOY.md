# Публикация «Умно — Математика» на Render

Это версия кода для публикации, подготовленная на основе последнего пакета `umno-v7-upgrade`. ZIP содержит проект в папке `umno-deploy` и **не содержит `umno.db`, паролей или персональных данных**.

## 1. GitHub

Создайте приватный репозиторий `umno-math`. Распакуйте этот архив и положите **содержимое** папки `umno-deploy` в корень репозитория. В GitHub должны лежать `app.py`, `wsgi.py`, `requirements.txt`, `render.yaml`, `templates/` и `static/`. Файлы `.env`, `umno.db`, `.venv/` не добавляйте.

На своём компьютере можно использовать GitHub Desktop: File → Add local repository (или File → New repository, если папка ещё не является репозиторием), Commit, затем Publish repository. При публикации выберите Private.

## 2. Render

1. Откройте https://dashboard.render.com
2. New → Web Service → GitHub → выберите приватный `umno-math`.
3. Language: Python 3.
4. Build command: `pip install -r requirements.txt`.
5. Start command: `gunicorn --bind 0.0.0.0:$PORT wsgi:app`.
6. Instance type: Free (только для демонстрации).
7. Environment: `COOKIE_SECURE=1`; создайте `SECRET_KEY` как длинную случайную строку через `Generate` в панели Render (или возьмите из `render.yaml` через Blueprint).
8. Нажмите Deploy. Адрес появится в панели Render.

## 3. Хранилище данных

Важно: на Render Free локальная SQLite-база **теряет изменения** после рестарта, остановки или развёртывания. Пока не установлена надёжная PostgreSQL, не регистрируйте настоящих учеников и не обещайте сохранение прогресса. Можно проверять публичные страницы и гостевой режим на тестовых данных.

Для постоянного хранения добавьте в Render переменную `DATABASE_URL` со строкой подключения к PostgreSQL. Код принимает стандартный формат `postgresql://...` (также преобразует `postgres://` в `postgresql://`). **Не выкладывайте строку подключения в GitHub и не присылайте её в чат.** PostgreSQL должна быть долговременной (не 30-дневный пробный экземпляр).

## 4. Что уже подготовлено

- Добавлен `gunicorn` в `requirements.txt`.
- `wsgi.py` запускает и инициализирует базу при старте приложения.
- `render.yaml` описывает пробный веб-сервис.
- Секретный ключ обязательно должен быть указан для Render.
- База SQLite, пароли и персональные данные не входят в архив.

## 5. Важно перед публичным запуском с пользователями

Это ещё учебная версия. До разрешения массовой регистрации необходимы: настройка постоянного хранилища, миграции схемы, тесты форм и авторизации, ограничение частоты запросов, журналирование ошибок без секретов, политика хранения и удаления пользовательских данных и проверка защиты аккаунтов. Для несовершеннолетних пользователей нужны соответствующие возрасту меры приватности и согласия.
