# Умно — единый архив для GitHub (ОГЭ + ЕГЭ)

Содержит предыдущую доступную сборку Умно, 100 новых авторских задач профильного ЕГЭ (теперь в новом учебном разделе 188), и пробный профильный ЕГЭ с таймером 235 минут, тремя вариантами, проверкой первой части и разбором второй. Есть новые ссылки в боковом и мобильном меню. `requirements.txt` включает `gunicorn`, чтобы не повторить ошибку Render `gunicorn: command not found`.

## Установка
1. Сначала сделайте резервную копию текущего GitHub-репозитория — архив собран из доступной здесь копии, а не напрямую из GitHub. Она может не содержать последних сторонних правок.
2. Распакуйте ZIP. Загрузите **содержимое** распакованной папки (а не дополнительную вложенную папку) в корень GitHub `umno-math` с сохранением вложенных `templates/` и `static/`.
3. Нажмите `Commit changes` и проверьте Render. Команда сборки `pip install -r requirements.txt`, команда запуска `gunicorn --bind 0.0.0.0:$PORT wsgi:app`. Render Environment: существующие секреты и `DATABASE_URL` оставить без изменения.
4. Проверьте страницы `/ege/advanced`, `/ege/mock`, `/oge/advanced`, `/oge/mock25/`, а также вход, регистрацию и страницу прогресса.
5. Если сайт не загружается, вернитесь к последнему рабочему коммиту и смотрите Render Logs.

## Особенности
- 100 новых заданий = 60 первой части и 40 второй части. Многие — числовые варианты одной модели; уровень сложности неодинаков.
- Пробник выбирает 1 задачу каждого номера 1–19; не идентичен официальным КИМ и не сохраняет результаты в БД. Автопроверка только № 1–12; № 13–19 — самопроверка.
- Таймер включается по кнопке и отсчитывает 235 минут, не блокирует отправку и не сохраняется при перезагрузке страницы.
- Стереометрические чертежи условные, геометрическую задачу нужно читать по тексту.
- Используется прежняя схема PostgreSQL без миграций. Не удаляйте таблицы или данные Neon.
- Python-модули протестированы синтаксически; продакшен-проверка Render+Neon нужна после публикации.
