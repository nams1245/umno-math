# Профильный ЕГЭ — проект 2027

Проект ФИПИ на октябрь 2026 года: 20 заданий, № 1–13 с кратким ответом, № 14–20 с развёрнутым; максимальный первичный балл 33, время 235 минут. **Проект может быть изменён до утверждения окончательных материалов.**

Обновлены: меню расширенного тренажёра, пробный ЕГЭ, ограничение администратора, список тем каталога. Добавлены учебные подборки по новым № 6, 13 и 17, а также по № 12. Сохранены идентификаторы ранее созданных заданий из Python-модулей.

**Внимание:** исторические записи таблицы Question/Attempt в Neon не перенумеровывались; старый основной каталог включает вопросы со старой нумерацией. Не следует автоматически переименовывать номера в существующей базе — это может разрушить смысл отчётов. Переносить их следует отдельно после проверки темы каждой задачи. Новые задачи в CMS допускают номер 20.

Новый учебный пробник содержит 13 автоматически проверяемых заданий и 7 заданий для самопроверки, при этом он **не является официальным КИМ** и не выставляет официальный суммарный балл из 33.

Установка: распаковать ZIP и заменить содержимое корня GitHub, сохранив SECRET_KEY, ADMIN_EMAIL и DATABASE_URL в Render Environment. Не удалять Neon. Перед публикацией сохранить старый репозиторий как резервную копию.
