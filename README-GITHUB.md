# Умно — готовая сборка для GitHub

Это объединённая сборка из предыдущих предоставленных версий с профильным ЕГЭ.

## Установка
1. Сделайте резервную копию текущего репозитория.
2. Загрузите **содержимое** этой папки в корень GitHub `umno-math` с сохранением путей `templates/`, `static/` и всех файлов `.py`. Не создавайте лишнюю вложенную папку.
3. В GitHub нажмите `Commit changes`. Проверьте `Deploy` на Render и логи, затем страницы `/oge/advanced`, `/oge/mock25/`, `/ege/advanced`.
4. Не удаляйте PostgreSQL Neon и не меняйте существующие Render `DATABASE_URL` и `SECRET_KEY`.

## Важно
- Сборка основана на последних **доступных в этой сессии архивах**, а не на прямом экспорте текущего репозитория. Если в GitHub есть более новые изменения, сравните файлы перед заменой.
- Если Render сообщил о сбое деплоя, верните последний рабочий коммит.
- Новые модули ОГЭ сохраняют черновики и пробные попытки в PostgreSQL; учебный раздел ЕГЭ пока не записывает попытки.
- Это авторские тренировочные задания, а не официальный банк ФИПИ.
