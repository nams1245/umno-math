# Админ-панель Умно v2

Это ПОЛНАЯ сборка на базе предыдущего архива, с прежними модулями ОГЭ и ЕГЭ.

Установка: сохраните резервную копию репозитория, распакуйте содержимое архива в корень GitHub (рядом с `app.py` находятся `admin_editor.py`, `wsgi.py`, `requirements.txt`; шаблоны внутри `templates`). Сделайте commit. Проверьте Render Live.

Render Environment: `DATABASE_URL`, `SECRET_KEY`, `ADMIN_EMAIL` (email вашей учётной записи в Умно, не пароль). Секреты не добавлять в GitHub.

Панель: `/admin/tasks` — фильтры, поиск, массовое опубликование/снятие с публикации/удаление авторских задач. `/admin/legacy` — скрытие (архив) и восстановление старых заданий, редактирование объяснения, теории и выбора правильного варианта (для теста).

`/tasks` показывает только опубликованные авторские задания. Архив старого банка сохраняет записи `question`, попытки и связи. Новая таблица `legacy_archive` создаётся автоматически при запуске `wsgi.py`; уже существующие таблицы не изменяются. **Важно:** старые задачи, заранее вставленные в отдельные Python-модули расширенного ОГЭ/ЕГЭ, не хранятся в `Question` и не управляются страницей `/admin/legacy`. Их редактирование требует отдельного переноса в Neon.

Ограничение: для старых заданий с ручным вводом ответ прописан в исходных Python-данных и из этого интерфейса не редактируется. История решений может содержать архивные задачи; это сделано намеренно. Перед публикацией проверьте работу на тестовом аккаунте.
