# Умно — обновление платформы (папка umno-v7)

Обновление к существующему проекту `umno-v7`: **ОГЭ + профильный ЕГЭ, только математика**.

## Новое

- Поиск по тексту, теме, номеру; фильтр по сложности (учебные ориентиры, не официальная градация).
- Избранные задания для зарегистрированных учеников.
- Конструктор вариантов с общей проверкой и результатом (доступен гостям).
- Исправлена ошибка переменной `manual` в `question()` и проверка текстовых числовых ответов.
- Пробный экзамен теперь также корректно проверяет ручные ответы.
- Прогресс по темам, процент правильных ответов, история пробников.
- Задания профильного ЕГЭ с номерами 13–19: отдельная форма развёрнутого решения, образец разбора и **самопроверка по учебному чек-листу** (0–3). Это НЕ экспертная автоматическая проверка и НЕ официальная шкала.
- Сохранены занятия без регистрации, учебные чертежи и кабинет учителя.

## Как установить без потери данных

1. Остановите Flask (`Ctrl+C`).
2. Сделайте **резервную копию** всей папки `umno-v7`, особенно файла `umno.db`.
3. Распакуйте архив; скопируйте **содержимое** папки `umno-v7-upgrade` в папку `C:\Users\exnot\Desktop\umno-v7` (где лежит `app.py`). Согласитесь заменить код и шаблоны.
4. **Не заменяйте `umno.db`**. Его нет в обновлении. При следующем запуске SQLAlchemy создаст только новые таблицы.
5. Запускайте с уже установленным Python-окружением:

```powershell
cd "$HOME\Desktop\umno-v7"
& "$HOME\Desktop\.venv\Scripts\python.exe" -m pip install -r requirements.txt
& "$HOME\Desktop\.venv\Scripts\python.exe" app.py
```

Откройте `http://127.0.0.1:5000`, обновите страницу `Ctrl+F5`.

## Новые страницы

- `/search` — поиск и фильтры.
- `/favorites` — избранное (для учеников с аккаунтом).
- `/constructor` — конструктор.
- `/my-variant` — собранный вариант с проверкой.
- `/progress` — расширенная статистика.
- `/extended/ID` — развёрнутое решение учебной задачи второй части профильного ЕГЭ.

## Ограничения

- Код проверен на синтаксис Python, но полноценное тестирование Flask-страниц в сборочной среде не выполнено из-за отсутствующих зависимостей.
- Уровни сложности приближённые. Материалы являются авторскими тренировочными заданиями; соответствие действующим критериям ЕГЭ не заявляется.
- Развёрнутые решения не оцениваются автоматически по реальным экспертным критериям: только самостоятельная проверка после раскрытия образца.
- Для публичного размещения нужны отдельные меры защиты и стабильный серверный секретный ключ.
