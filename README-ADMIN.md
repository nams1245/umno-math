# Умно: управление заданиями прямо на сайте

## Установка

1. Создай резервную копию GitHub-репозитория. Распакуй ZIP и загрузи **содержимое** папки в корень репозитория `umno-math`, сохраняя пути `templates/`, `static/`.
2. Сохрани Commit changes. В Render → `umno-math` → **Environment** добавь `ADMIN_EMAIL` с **точным email твоей существующей учётной записи** (которую ты сам зарегистрировал в «Умно»). **Не отправляй пароль или ADMIN_EMAIL в чат и не прописывай их в GitHub.**
3. Убедись, что `DATABASE_URL` и `SECRET_KEY` продолжают существовать в Render Environment. Не удаляй их. Сайт должен показать `Live`.
4. Войди в сайт с этой учётной записью, открой `https://umno-math.onrender.com/admin/tasks`.
5. Нажми «Добавить задачу», укажи ОГЭ/ЕГЭ, номер задания, условие, ответ, решение, при необходимости загрузи изображение PNG/JPG/WebP (до 2 МБ). Поставь галочку «Опубликовать» и нажми «Сохранить».
6. Опубликованные задачи увидят все по ссылке `/tasks`. Черновики доступны только владельцу через админ-панель.

## Безопасность / ограничения

- Админ-доступ проверяется на сервере по точному email, заданному **только** в Render Environment, плюс действующий вход с паролем. Кнопка не даёт доступ сама по себе.
- Никто не может создать администратора через обычную форму регистрации. Настрой ADMIN_EMAIL на уже существующий **твой** аккаунт.
- Встроенная защита CSRF защищает формы POST. Картинки только PNG/JPG/WebP; SVG/HTML запрещены из соображений безопасности.
- Задачи хранятся в таблице `managed_task` в PostgreSQL Neon. При запуске `db.create_all()` создаёт её при необходимости. Данные сохраняются между перезапусками Render.
- Старые задания из пакетов ОГЭ/ЕГЭ остаются без изменений. Новый редактор управляет **новыми** заданиями в отдельном публичном каталоге `/tasks` — это специально сделано, чтобы не сломать базовый банк и результаты учеников.
- Загрузка изображения в Neon прямо в БД допустима для небольших файлов. В будущем можно подключить внешнее файловое хранилище.
- Ученик может открыть задание и разбор; автоматической оценки ответа и включения в пробные варианты для этих новых заданий пока нет.
- Если ты заметишь RuntimeError/ImportError в Render, верни прежний коммит GitHub и пришли только текст ошибки (без секретов).
